# Hash Checker v1.0

Windows용 초고속 대용량 및 압축 파일 무결성 해시 검증 유틸리티입니다.  
High-speed large file & archive (`.zip`, `.7z`) hash verification utility for Windows.

## 주요 기능 (Features)
- **4대 해시 동시 계산 (Single-Pass):** CRC32, MD5, SHA1, SHA256 값을 한 번의 읽기로 동시에 계산
- **압축 파일 내부 직접 검증:** 내장 7-Zip 고속 스트리밍 엔진으로 `.zip`, `.7z` 내부 파일 해시 산출 (한중일 파일명 완벽 지원)
- **실시간 해시 비교:** 입력칸 붙여넣기 즉시 일치 여부, 알고리즘 구분, 일치 파일명 표시
- **탐색기 우클릭 메뉴 연동:** 관리자 권한 없이 현재 사용자 우클릭 메뉴 등록/해제 지원
- **4개국 언어 지원:** 한국어(KR), 영어(US), 일본어(JP), 중국어(CN) 실시간 전환
- **무설치 단일 포터블 실행 파일:** 별도 설치 없이 `HashChecker.exe` 단독 실행
